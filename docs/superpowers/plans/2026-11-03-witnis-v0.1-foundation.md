# Witnis v0.1 Foundation Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Do **not** create or push a public GitHub repository.

**Goal:** Locally index a Python fixture repo into SQLite and expose working `witnis index|overview|search` CLI commands with a reproducible demo.

**Architecture:** Python package `witnis` with a small Core (scan → parse symbols via Python `ast` → SQLite) and a CLI adapter. MCP / Studio / Verification are out of scope for v0.1. Tree-sitter can replace/extend the Python analyzer later without changing CLI contracts.

**Tech Stack:** Python 3.12+, stdlib `ast` + `sqlite3`, `typer` (or argparse if keeping zero deps), `pytest`.

## Global Constraints

- No `gh repo create`, no public remote, no public push (release gate).
- No Cursor/AI co-author trailers in commits.
- Read-only toward the target repo (never modify indexed project files).
- Honor `.gitignore` / skip secrets-ish names (`.env`, `*.pem`).
- English CLI help text.
- Core facts must not require an LLM.
